wrote it should be able to, and the log proves the history.

## Program naming convention (agree as a team)

Example: `M03-audiomap-v4` — mission number, short name, version.
Keep it consistent so tournament-day loading is stress-free.

## Programming patterns we know (kids check off as they learn/use)

- [ ] Move straight for X cm/rotations
- [ ] Turn in place (wheel-count)
- [ ] Gyro-accurate turns
- [ ] Line following with color sensor
- [ ] Wall squaring (drive into wall to self-align)
- [ ] My Block / function for repeated maneuvers
