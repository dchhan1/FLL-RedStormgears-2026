# Admin

Roster, forms, inventory, and budget. Keep personal contact info minimal —
a first name + parent email is enough here; store signed forms somewhere secure.

## Files

- [team-roster-and-forms.md](team-roster-and-forms.md) — who's on the team and what paperwork is done
- [inventory.md](inventory.md) — what you own, where it lives, what's missing

## Recurring admin tasks

- Registration renewal: team registration + event registration each season
- Background screening: every coach/mentor, every season (takes days–weeks, start early)
- Consent + media release forms: before the first meeting
- Inventory check: pre-season and pre-tournament
- Budget: registration, spare parts, event travel, team shirts (optional)
