# Season Plan

Work backwards from your event date. The arc below assumes a **~14-week, 2×/week
season (Sept → early Dec qualifier)**. If your event is in November, compress by
starting the robot game in week 1 and overlapping phases.

## Files

- [season-calendar.md](season-calendar.md) — fill-in calendar grid, week by week
- [week-by-week-arc.md](week-by-week-arc.md) — what each phase must achieve + milestones
- [lessons-notes.md](lessons-notes.md) — running notes for next season (fill as you go)

## Phase overview (2×/week, ~2 hr meetings → ~4 hr/week)

| Weeks | Phase | Both meetings look like |
|---|---|---|
| 1–2 | Kickoff & foundations | Team building + build mission models; robot basics |
| 3–4 | Early robot + project launch | Robot: first mission; Project: pick the problem |
| 5–8 | Mid-season grind | Meeting A = robot, Meeting B = project (swap as needed) |
| 9–11 | Integration | Chain missions, build reliability, draft presentation |
| 12–13 | Rehearsal | Mock judging, mock tournament, polish |
| 14 | Tournament week | Light touches only; confidence and rest |
