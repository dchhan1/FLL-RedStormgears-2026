# Core Values

FLL's six Core Values are judged directly at tournaments and shape every
meeting. We do a 10-minute activity at the start of every session.

## The six values (this season's official wording may vary slightly — check the season documents)

| Value | In practice for a 5th–6th grade team |
|---|---|
| **Discovery** | We explore new skills and ideas — trying and failing counts |
| **Innovation** | We use creativity and persistence to solve problems |
| **Impact** | We apply what we learn to improve our world |
| **Inclusion** | We respect each other and embrace our differences |
| **Teamwork** | We are stronger when we work together |
| **Fun** | We enjoy and celebrate what we do! |

Alongside these, FIRST's philosophies of **Gracious Professionalism** and
**Coopertition** (competing while helping others) run through everything.

## Coach notes

- Judges often watch teams at the practice table and in the pit, not just in
  the Core Values session — the values have to be real, not rehearsed.
- At judging, expect a hands-on team challenge on the spot: they'll be given a
  surprise task and watched on how they work together, plus how they talk
  about their season. Practice mystery challenges ([activities](team-building-activities.md) #7, #8).
- When conflicts arise at meetings, refer to the team's own written norms
  rather than imposing a ruling.
