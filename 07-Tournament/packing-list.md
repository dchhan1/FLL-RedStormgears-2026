# Tournament Packing List

Pack the night before. Bins beat bags — one for robot, one for admin, one for food.

## Robot

- [ ] Robot (in a crash-proof box, not loose in a bag)
- [ ] **All attachments**, labeled by run
- [ ] Spare parts bin: pins, axles, connectors, gears, spare wheels, rubber bands
- [ ] Spare large motor + medium motor if you own them
- [ ] Laptop/tablet with all programs, **plus a backup copy** (USB stick or cloud)
- [ ] USB cable + **USB download cable** (no Bluetooth allowed at the table)
- [ ] Hub charger
- [ ] Alignment jig / launch template (cardboard cutout) if you use one

## Field reset aids

- [ ] Run sheets (2 printed copies — one for the pit, one for the operator)
- [ ] Field reset map (photo of correct field state on your phone, printed too)
- [ ] Small brush/towel for wheels if the venue floor is dusty

## Project & judging

- [ ] Portfolio copies (2–3)
- [ ] Robot Design Executive Summary (RDES), extra copies
- [ ] Presentation props / prototype
- [ ] Cue cards (kid-made)
- [ ] Copy of the presentation script as backup (kid-written)

## Admin

- [ ] Team info: team number, coach contact, event schedule printed
- [ ] Consent/media forms (digital or paper, per event requirements)
- [ ] Extension cord + power strip (pit power is never where you need it)
- [ ] Painter's tape (pit/cord labeling, marking your reset zone)
- [ ] First-aid basics: band-aids, tissues
- [ ] Cash/card for t-shirts or lunch

## Comfort & morale

- [ ] Water bottles + snacks (kids crash without food — schedule snack times)
- [ ] quiet downtime stuff: cards, book
- [ ] Sign or banner if you made one; markers for pit decorating
- [ ] Camera charged; someone assigned as photographer

## Don't pack

Anything the team isn't prepared to explain — no last-minute additions made
by adults. If it's not kid-made, it doesn't go.
