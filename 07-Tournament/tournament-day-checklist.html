Tournament Day Checklist

Week before

  • Confirm event location, arrival time, and the team's session schedule
  • Verify registration details: team number, roster signed in, any waivers
  • Full dress rehearsal: best-of-3 rounds on a freshly reset field
  • Presentation performed for parents or another friendly audience
  • Robot inspected by the team against this season's rules (size, motors,

    • parts legality — read the official Robot Game rules section on this)

  • Charge hub, tablets/laptops; pack chargers + power strip
  • Print: run sheets, presentation cue cards, portfolio + RDES copies, schedule
  • Kids pack: water bottle, snacks, book/cards for downtime, team shirt if any
  • Plan lunch (pack or buy?) and a meeting point if families split up

Night before

  • Everything packed per packing-list.md; bins staged by the door
  • Hub charged; backup batteries if used
  • Check weather / travel time; plan to arrive 15+ minutes early
  • Early bedtime speech: "The goal is to show what we know and have fun."

Arrival (first 30 minutes)

  • Check in; get schedule; send two kids to scout: practice table location,

    • judging rooms, restrooms, staging area

  • Set up pit area; tape down a mini "reset zone" map for field reset
  • Robot passes inspection (fix anything flagged — inspectors are helpful)
  • One calm practice round on the event's practice table if available;

    • note how the table differs from yours

Between sessions

  • After each robot round: kids log score, pick max ONE improvement,

    • execute the pre-agreed fallback if a run failed badly

  • Rotate table operators as planned; every kid gets table time
  • Visit other teams' pits; compliment specific things ("your attachment

    • swap is so fast") — Coopertition in action

  • Eat, drink, breathe — the coach's job is morale

After the last round

  • Team photo, regardless of results
  • Thank judges, referees, volunteers (kids do the thanking)
  • Watch the awards ceremony; cheer for other teams like you mean it
  • Post on the ride home: everyone shares one favorite moment
