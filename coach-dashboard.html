Workstreams

Three things run in parallel

Robot Game

Consistency beats peak score: rank missions by (points × success rate) ÷ time and bank easy ones first.

  • Start from a proven one-kit base (DroidBot 3M, Educator++), then let the team’s own iteration story happen on top
  • Skill ladder: drive → turns → sensors → attachments → My Blocks → navigation
  • Reliability bar: 5 clean runs in a row before a mission counts
workspace: 03-Robot-Game/

Innovation Project

Problem → research → innovative solution → feedback → share. Kid-chosen, expert-informed.

  • Expert outreach is the #1 bottleneck — start emails in week 3 (template ready)
  • Brainstorm wide, then one precise problem statement
  • Seed ideas for biodiversity and living light on file
workspace: 04-Innovation-Project/

Core Values & Judging

Three judged sessions carry as much weight as robot score — rookie teams win through them.

  • 10 minutes of team-building opens every meeting
  • Engineering notebook from day one: failed attempt → fix → measured result is judging gold
  • Every kid speaks; RDES written by kids, printed ×3
workspace: 05 · 06 · 07
