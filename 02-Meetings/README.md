# Meetings

One folder per week, one file per meeting. The two weekly meetings follow a
rhythm: **Meeting A leans robot, Meeting B leans project** — but every meeting
opens with Core Values and closes with reflection.

## The standard 2-hour agenda

| Time | Block | Notes |
|---|---|---|
| 0:00–0:10 | Opening + Core Values activity | Short game or challenge; preview today's goals |
| 0:10–0:20 | Stand-up: what did we decide last time? | Kids re-read their own notes — not the coach |
| 0:20–1:45 | Work blocks (robot / project) | See splits below |
| 1:45–1:55 | Demo + reflection | Show what worked; record in notebook |
| 1:55–2:00 | Clean-up + preview next meeting | Field reset is part of the job |

**With 4 kids** (Andrew, Eric, Emily, Ethan), run one workstream per meeting
with everyone together, or split 2+2 across robot/project when both need time
(good default pairs: one 6th grader with Ethan).

### Meeting A (robot-leaning)

- 0:20–1:00 — Robot work: skills lesson or mission programming
- 1:00–1:10 — Movement break
- 1:10–1:45 — Mission testing + logging results; or project quick-task

### Meeting B (project-leaning)

- 0:20–1:00 — Project work: research, expert prep, presentation building
- 1:00–1:10 — Movement break
- 1:10–1:45 — Robot: run reliability practice (every run logged)

## Files

- [meeting-plan-template.md](meeting-plan-template.md) — copy this for each meeting
- [week-01/](week-01/) — kickoff week, fully planned as the model

## Coach habits for every meeting

1. Start on time with the kids running the opening, not you.
2. Take 5 photos per meeting minimum (robot iterations, whiteboards, kids working).
3. Write nothing in the notebook yourself — a kid is the scribe each meeting.
4. End with "one thing that worked, one thing to change" from every kid.
