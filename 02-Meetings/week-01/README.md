# Week 01 — Kickoff

Two meetings: launch the season, build the field, bond the team, first robot
movement. Goals: every kid has driven the robot and every kid can name the
six Core Values by the end of the week.

## Meeting 1-A — Season launch (2 hrs)

**Prep:** season documents printed/open, kickoff video queued, SPIKE kits ready,
engineering notebooks (or this folder) ready.

| Time | Activity |
|---|---|
| 0:00 | Welcome; coach intro — what FLL is, what the season looks like (keep to 5 min) |
| 0:05 | **Watch the season kickoff video together** |
| 0:20 | Core Values intro: the six values on poster paper — kids give examples of each |
| 0:35 | Team identity: we're the **Red Stormgears** — design a logo/poster and agree how we introduce ourselves |
| 0:50 | Break |
| 1:00 | **Build mission models** — split bags among kids, build in parallel |
| 1:45 | Field tour: place models on the mat; quick tour of each mission area |
| 1:50 | Reflection + preview: next time we drive the robot! |
| 2:00 | Clean-up (field stays set up if you have a permanent table) |

## Meeting 1-B — First drive (2 hrs)

| Time | Activity |
|---|---|
| 0:00 | Core Values game: pick from [team-building-activities](../../05-Core-Values/team-building-activities.md) |
| 0:10 | Stand-up: re-read meeting 1 notes; set today's goals |
| 0:20 | **Build/verify the SPIKE drive base** (returning members lead, new members drive the build) |
| 0:50 | Break |
| 1:00 | First program: move forward 50 cm, stop. Then: can you hit a specific line? |
| 1:30 | Mini-challenge: push a ball across the mat into a box — measure, adjust, retry |
| 1:50 | Reflection; scribe logs "week 1" notebook entry |
| 2:00 | Clean-up |

## Coach notes

- Mission model bags are numbered — keep parts of a bag together until built.
- Let returning members teach new members; coach stays out of the build.
- If kit sorting is chaotic, spend 10 min on a parts-organizing system now — it pays back all season.
