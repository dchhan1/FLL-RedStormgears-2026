Judging Portfolio

Evidence the team shows judges in the three judged sessions: Robot Design, Innovation Project, and Core Values. Kid-made and kid-owned: a polished adult binder reads as exactly that to judges. Authentic, messy-in- the-right-places evidence with kids who can talk about it wins.

Structure (digital or physical binder — team's choice)

  1. Team page — the Red Stormgears name/logo, members, photo, one line each ("I lead programming…")
  2. Season story — 5–10 photos over time with kid-written captions
  3. Robot Design — from 03-Robot-Game:

    4. design evolution log, code screenshots, run strategy, score logs, and the Robot Design Executive Summary (RDES) — a one-pager (strategy, chassis, attachments, programming highlights) that steers judges' questions; check this season's materials for the current template

  4. Innovation Project — from 04-Innovation-Project:

    5. problem statement, research log, expert quotes, solution & feedback loop

  5. Core Values — from 05-Core-Values: reflections,

    6. WWW/EBI log, photos of team activities

Preparation checklist (weeks 12–13)

  • Every kid can explain: one robot design decision, one program, the

    • project problem & solution, and what Core Values looked like for them

  • Two full mock judging sessions done with a non-coach adult
  • RDES written (every word by kids) and printed — bring extra copies
  • Portfolio printed/assembled; every kid has held and paged through it
  • Kids prepared to answer "who did what" honestly
  • Quiet kid has at least one guaranteed speaking moment (plan it, own it)
