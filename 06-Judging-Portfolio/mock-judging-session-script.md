# Mock Judging Session Script (for the adult playing judge)

Run this twice, in weeks 12 and 13, with a non-coach adult if possible
(another parent works great — unfamiliar faces add realistic pressure).
Give this script to the "judge"; the team should NOT read it beforehand.

Note: event formats vary by region — some run three separate sessions as
below; others combine everything into one ~30-minute judging block (project
presentation, robot Q&A, and a teamwork activity back-to-back). Check your
event's schedule and practice whichever shape you'll face; the content below
covers both.

## Setup

Room with table and chairs, ~10 minutes per session, team brings its
portfolio. Judge stays friendly but neutral — no coaching during the session.

## Session 1 — Innovation Project (~10 min)

1. "Welcome! Tell us about your project." (team presents, ~5 min — time it)
2. Q&A (~5 min), pick 3–4:
   - Why this problem?
   - How do you know your research is accurate?
   - What makes your solution innovative?
   - How did you use your expert's feedback?
   - What would you improve with another month?
3. One wildcard: "If your solution existed tomorrow, who would use it first?"

## Session 2 — Robot Design (~10 min)

1. "Show us your robot and tell us how you designed it." (~5 min)
2. Q&A, pick 3–4:
   - Walk me through what this program does. (point at the longest one)
   - Why did you choose this drive base / these wheels?
   - Show me an attachment and why you built it that way.
   - What broke most often? How did you fix it?
   - Which mission is hardest, and why?
3. Ask a quiet member one question directly: "What part did you work on?"

## Session 3 — Core Values (~10 min)

1. Surprise hands-on challenge (5 min): give the team an untried task with
   simple materials — e.g., paper bridge spanning two books that holds a
   marker, or "invent a game using these 3 objects." Watch silently:
   - Does everyone participate? Do they listen? Do they build on each other's ideas?
2. Q&A (5 min):
   - What's a time this season your team disagreed? What happened?
   - Which Core Value was hardest for your team?
   - What will you remember from this season in five years?

## After all three: judge's feedback form

| Area | What impressed me | One thing to work on |
|---|---|---|
| Innovation Project |  |  |
| Robot Design |  |  |
| Core Values |  |  |

Deliver feedback kindly and only after all sessions end. Coach writes none of
it down for the kids — the team records what they took from it.
