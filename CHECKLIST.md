# Master Season Checklist — BIOGLOW (FIRST CANOPY)

## 1. Pre-season (now — first meeting)

- [ ] Register the team with FIRST (and your regional delivery partner) for the current season
- [ ] Recruit a **second registered adult coach/mentor** (FLL requires two screened adults) — even a rotating parent counts if consistent
- [ ] Complete coach background screening / Youth Protection Program requirements
- [ ] Collect signed consent + media release forms from every family (log in [00-Admin](00-Admin/team-roster-and-forms.md))
- [ ] Confirm equipment: SPIKE Prime kit, hub charges, field table, season mat + mission model bags
- [ ] Download this season's official documents: **Challenge (missions + rules), Challenge Guide (Innovation Project + Core Values), rubrics** — from the official FIRST LEGO League site
- [ ] Watch the official season kickoff / challenge release video together or before meeting 1
- [ ] Set the meeting schedule (2×/week, 2 hrs) and share with families
- [ ] Set up a laptop/tablet with the SPIKE app per team; update firmware on hubs
- [ ] Read the Robot Game rules yourself — you don't need every detail, but know where to look
- [ ] Plan the season calendar ([01-Season-Plan/season-calendar.md](01-Season-Plan/season-calendar.md)) against your event date
- [ ] Optional: set up a shared photo stream / folder for documentation

## 2. Kickoff (first 1–2 weeks)

- [ ] Team norms & expectations created **by the kids** (write them down, post them)
- [ ] Core Values session: what are the six values? What do they look like in practice?
- [ ] Build all mission models together and set up the field — this teaches the theme
- [ ] Walk through every mission: what does the robot have to do? What earns points?
- [ ] Kids do the season math: max points, and which missions look easy/medium/hard
- [ ] Robot basics for new members: hub, motors, ports, first drive program
- [ ] Start the engineering notebook / documentation habit from day one

## 3. Early season (weeks 1–4)

- [ ] Robot: drive base built; drive straight, accurate turns (wheel vs. gyro)
- [ ] Robot: complete first easy mission end-to-end (align → go → return or finish)
- [ ] Project: understand the BIOGLOW theme (biodiversity & nature–human balance); brainstorm problems kids actually care about
- [ ] Project: pick ONE problem and define it precisely (who/what/where/why)
- [ ] Project: start the research log; find at least 2 good sources
- [ ] Identify and contact a community/theme expert (professor, professional, museum, etc.)
- [ ] First mission analysis sheet filled in and prioritized

## 4. Mid-season (weeks 5–10)

- [ ] Robot: 2–3 reliable missions chained in one run; alignment jigs for consistency
- [ ] Robot: attachments (passive first, then powered); quick-swap design
- [ ] Robot: save code versions by date; kids can explain every program
- [ ] Project: brainstorm many solutions, then choose one innovative solution
- [ ] Project: prototype / model the solution; get feedback from an expert or user
- [ ] Project: iterate based on feedback and document what changed
- [ ] Run strategy: run sheets written; know expected points and success rates
- [ ] Mid-season self-check against all three judging rubrics (Robot Design, Innovation Project, Core Values)

## 5. Late season (weeks 11–15)

- [ ] Robot: push reliability — every run tested 5+ times in a row without failure
- [ ] Robot: decide the final run list (lock scope! no new missions in the last 2 weeks)
- [ ] Project: presentation written and rehearsed (typically ~5 min + judge Q&A — confirm format in this season's documents)
- [ ] Portfolio assembled by the kids ([06-Judging-Portfolio](06-Judging-Portfolio/))
- [ ] Mock judging sessions ×2: run full Robot Design, Project, and Core Values sessions with another adult as "judge"
- [ ] Practice Q&A hard: every kid answers questions, not just the confident one
- [ ] Full mock tournament: best-of-3 robot runs with a stranger resetting the field

## 6. Tournament week

- [ ] Pack using [tournament-day-checklist](07-Tournament/tournament-day-checklist.md)
- [ ] Charge everything; test robot on a **different table surface** if possible
- [ ] Print run sheets, presentation script, portfolio copies
- [ ] Remind families: schedule, location, arrival time, what to bring
- [ ] Prep the kids for outcomes: celebrate effort and Core Values, not just trophies

## 7. Tournament day

- [ ] Arrive early; find pit area; send a scout for schedule/venue layout
- [ ] Robot inspection: verify size limits, number of motors/attachments per rules
- [ ] Between rounds: reset robot, re-check attachment wear, breathe, hydrate
- [ ] Watch and cheer for other teams (Coopertition!)
- [ ] Thank the volunteers and judges
- [ ] Take the team photo

## 8. Post-season

- [ ] Debrief meeting: WWW / EBI (What Went Well / Even Better If) — write it down for next year
- [ ] Archive this season's folder; save final code and photos
- [ ] Thank-you notes to experts, sponsors, venue hosts
- [ ] Celebrate! If advancing, repeat late-season mode for the next event
- [ ] Capture what you learned in [01-Season-Plan](01-Season-Plan/) notes for next season
